# 実装時の受入チェックリスト

更新：2026-09-13。WordPress 7.1 / PHP 8.3 / Playground SQLiteで実行した範囲を反映。MySQLとブラウザーの全画面幅確認は未完了。

## Phase 1

- [ ] WordPress・PHP・DBの採用バージョンを記録し、管理画面とパーマリンクが動作する。
- [ ] プラグイン有効化・再有効化でデータが重複せず、テーマ変更後もCPTを管理できる。
- [x] article / municipality / companyの登録・保存・再表示ができる（統合テスト・HTTP確認）。
- [ ] article_typeなし・複数指定を拒否し、5種類の正規URLを解決する。
- [ ] 異なる都道府県と市区町村の組合せ、無効URL、未来の確認日を拒否する。
- [x] 未確認情報・取材根拠のないスタッフ記事を共通の公開処理で拒否し、RESTの変更と直接公開・cron相当の経路を検証する。
- [ ] 出典・確認担当・確認日時と重要フィールドの変更履歴を保存する。
- [ ] 未登録データを「未確認」と表示し、料金・営業時間・口コミ・実績を補完しない。
- [x] 自社・提携の表示と掲載停止が機能する（業者詳細HTTP・状態変更テスト）。
- [ ] 7カテゴリーとトップの指定10セクションが実データまたは適切な空表示で動作する。
- [ ] 自治体階層、業者詳細、ページ送り、404にルート衝突がない。
- [ ] 幅375px・768px・1280px、200%拡大、キーボード操作で本文・導線が利用できる。
- [ ] PHP構文・規約チェックとWordPress/DB統合テストに合格する。

## 後続Phase

- [ ] index対象・canonical・サイトマップ・Schemaが同じ公開データを参照する。
- [ ] AIアカウントが公開・個人情報取得・既存記事直接上書きを行えない。
- [ ] Leadの同時登録・二重クリック・再送でも一意な受付になる。
- [ ] 送客同意のない業者、停止業者への送信を拒否する。
- [ ] DB保存成功後に配信が失敗してもLeadを保持し、配信不明時に重複送信しない。
- [ ] 他の権限でLead個人情報・台帳へアクセスできない。
- [ ] 成約取消・通知重複・多社送客を含む台帳集計が正しい。
- [ ] GSCとGA4が未接続・失敗・欠測の場合にゼロ実績と誤表示しない。
- [ ] GSC再取得で二重計上せず、個別Leadへクエリを捏造して紐付けない。
- [ ] バックアップ復元、秘密情報分離、個人情報削除を検証する。
