# 初期コンテンツパック

2026-09-19調査。全国向け解説4本・公式情報をもとにした業者候補3社。ユーザー指定の地域・提携企業はなく、全国向け解説と公式情報を確認できる候補の準備として作成。

`index.html` から各原稿を閲覧できます。`bundle.json` は本文・抜粋・分類・出典・主張リスト・業者項目を含む取り込み用データ。`build.mjs` が編集元です。修正後は `node content/initial/build.mjs` でHTMLとJSONを再生成します。

業者は推薦順位ではありません。公式サイトの説明を整理しており、サービス品質の独自審査や企業への取材・連絡は未実施。全社で運営者との関係・広告提携の有無が未確認です。対応地域分類を推測で登録しません。`partner_status=none` は取り込み上の仮の初期値であり、一般掲載として確定したという意味ではありません。`listing_status=draft`、`ownership_relation=unknown` のため公開確認を通過できません。

スタッフ記事は実取材がないため、速報記事は新しい発表資料の選定をしていないため含めていません。自治体詳細は対象地域未指定のため含めていません。

## ローカルへの取り込み

起動済みのプレビューを終了してから実行します。

```powershell
node scripts/playground.mjs --seed-initial
```

7件を下書きとして保存します。記事は既存の「記事制作」企画と主張確認画面にも登録。AIの主張確認はすべて要確認で、人による確認日を自動入力しません。取り込み結果のIDは `.runtime/initial-import.json`。

再実行は既存IDを返し、編集済みの本文・公開状態を上書きしません。元パックを修正しても既存記事には反映しないので、取り込み後の修正はWordPress編集画面で行います。途中で失敗した記録は停止して調査し、ロックを無条件に削除しないでください。

## 本番への取り込み

テーマ・Cleanup Core有効化済みのWordPressに、このフォルダー一式をWeb公開ディレクトリの外へ配置し、WP-CLIで実行します。以下のパスとユーザーは実環境の値へ置き換えてください。コマンドは本番では未実行です。

```text
wp --path=/path/to/wordpress --user=EDITOR_ID eval-file /private/content/initial/import.php
```

実行には情報編集権限が必要です。公開やSEO承認は行いません。

## 公開するまで

1. 「情報確認 → 記事制作」で出典と本文全体を照合。主張リストに漏れがあれば本文と合わせて確認する。
2. 記事編集で確認日を入力し、主張ごとに確認結果と根拠を保存する。
3. 業者は未確認項目、対応する都道府県・サービス、広告提携区分と運営者との関係を確認して入力する。掲載状態を変更する前に回収主体等を照合する。
4. 公開確認画面から人が公開を承認する。検索掲載の承認は別途行う。

資料調査日と人による公開確認日は別です。原稿HTMLの注意欄はレビュー用表示で、投稿本文には入りません。
